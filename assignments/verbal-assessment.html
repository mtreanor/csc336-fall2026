Final Verbal Assessment

This is required to receive a grade in this class.

When: the last week of class (Tue 12/8 through Fri 12/11), at your scheduled time.

What It Is

Every student will have a short, one-on-one conversation with me about their work. This is required.

  • It takes 5 to 8 minutes. I'll show you a small code project that I wrote and ask you to explain various aspects of it: how a piece of it works, why it's written the way it is, what would happen if something changed.
  • The project is a distilled version of what we've covered in class, covering everything from the start of the semester up through basic databases. Nothing in it is new or tricky. It represents the high-level understanding I think you should have coming out of this course.
  • I'll tell you how you did right then and there. No waiting for a grade to show up later. You'll get an indication of 0, 1, 2, or 3 using the verbal assessment criteria in the syllabus.

When Is Mine?

Your time is posted on the spreadsheet on the main Canvas page for the class. Check it, and put it in your calendar.

What About Class That Week?

The class sessions that week are for you to workshop your project. Feel free to work together and talk through your code with each other. Explaining code out loud to a classmate is great practice for the assessment.

How to Prepare

I won't share the project ahead of time. Instead, there is a list of topics we've covered this semester. The project is built from those topics, so that list is what to study.

  • Go through the list and, for each topic, try explaining it out loud in your own words. If you can't, look back at that day's class example.
  • Practice reading code you didn't write. Open a class example, pick a line, and explain what it does and why it's there.

A Note About Nerves

I know some people are more comfortable than others being put on the spot like this. No one is going to fail based on their performance. This is my best attempt to give you honest feedback, and I think that kind of feedback will be valuable in your professional life.
